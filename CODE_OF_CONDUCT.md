# Code of conduct

Everyone participating in this project should be treated with respect,
regardless of experience, identity, nationality, background, or viewpoint.
Welcome questions, explain technical disagreements with evidence, and give
constructive feedback about the work. Respect privacy and access boundaries.

Harassment, threats, discriminatory language, unwanted contact, doxxing,
publication of credentials or private account data, and deliberate disruption
are unacceptable in issues, reviews, discussions, and other project spaces.

Report concerns privately to the repository owner through their GitHub profile.
Do not publish sensitive evidence in a public issue. Maintainers will assess
reports confidentially where possible, seek context, and may remove content,
warn participants, restrict participation, or ban repeat or serious offenders.
Maintainers must apply these standards consistently, disclose conflicts of
interest, and allow affected participants to provide additional context.
